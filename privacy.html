Orbit Ecomm

eBay API privacy notice

Updated 24 October 2026

This notice covers the eBay seller API connection, listing and inventory jobs, order reads, and account-deletion processing for a privately operated Orbit installation. The account owner controls this installation; it is not a public service for other sellers.

Information used

After the owner approves access on eBay, Orbit uses the seller's user ID, username, granted permissions, authorization dates, and access and refresh tokens. eBay handles sign-in; Orbit does not receive the eBay password.

The API workflow uses product source links and facts, selected photographs, listing descriptions and specifics, prices, stock, business-policy and inventory-location identifiers, offer and listing identifiers, operation checkpoints, and inventory snapshots. Order sync retains order and item identifiers, quantities, amounts, dates, and payment and shipment status. Buyer names, contact details, and delivery addresses returned during order sync are excluded from the cached order records.

When the owner prepares fulfillment for a paid order, Orbit verifies that original order again and reads its delivery name, address, and phone number. The structured address is held temporarily in the extension's session storage and passed to the selected Amazon checkout. It is cleared when preparation finishes, fails, or is cancelled. The API fulfillment path does not send that address to an AI service and does not submit the final Amazon purchase.

Storage and providers

The local backend exchanges and refreshes authorization directly with eBay. Seller authorization, API product plans, photo receipts, inventory and order metadata, and write checkpoints are encrypted with Windows DPAPI for the current Windows user and stored on the operator's PC. Chrome also retains queue progress and separate product-source records. Seller access and refresh tokens are not returned to the extension, the notification service, or AI services.

Selected product photos are uploaded to eBay. Product facts may be sent to the configured OpenAI service to prepare listing copy, categories, and item specifics; seller tokens and buyer delivery addresses are excluded from those requests. eBay and, when fulfillment is requested, Amazon process the information needed for those operations under their own policies.

The deletion endpoint runs on Cloudflare Workers. After verifying eBay's signature, it stores the notification payload, account identifiers, event dates, and receipt time in a private Cloudflare D1 inbox. Application verification credentials are held as Worker secrets. Cloudflare processes service and network metadata. GitHub Pages hosts this public notice and receives normal web-request metadata.

Retention and account controls

Disconnect this PC in Orbit Settings removes the saved seller authorization. It does not end eBay listings, remove inventory or order history, or erase other Orbit stores. Remove Orbit's authorization in eBay account settings to withdraw the eBay grant.

While the local backend is running, it reads verified deletion requests from the private inbox. It erases the matching backend API account records and authorization before acknowledging the notification. Acknowledgement removes the notification's personal payload and account identifier from the inbox; limited deduplication and processing metadata remain. Requests wait in the private inbox while this PC is offline. If the inbox cannot be checked, new API data operations pause.

This automatic deletion covers the backend API journal and authorization. Independent legacy browser product, order, source, queue, monitoring, and fulfillment stores are not automatically erased by this consumer. The operator must manage those separately. This notice does not claim that every legacy Orbit record is covered by the new API deletion process.

Limits and contact

This workflow adds no advertising trackers and does not sell account data. The account owner controls local access, backups, and retention. Other optional browser and AI tools can have separate data flows. For a question or data request, contact the operator who provided this installation. If Orbit is offered to other users, the operator must update this notice and provide an appropriate public contact method before connecting their accounts.
