Orbit Ecomm

eBay connection privacy notice

Updated 24 October 2026

This notice covers the eBay API seller connection and account-deletion notification service for a privately operated Orbit installation. It describes the current setup, not a public service for other sellers.

Information used by the seller connection

When the account owner chooses Connect eBay and approves access on eBay, Orbit requests permission to identify the seller, manage inventory and listings, and read selling policies. The connection stores the seller's eBay user ID, username, granted permissions, authorization dates, and access and refresh tokens. It does not request personal email, address, phone, payment, or order permissions.

eBay handles sign-in. Orbit does not receive the eBay password. API listing and inventory jobs are not enabled in this initial connection setup.

Storage and service providers

The local backend exchanges and refreshes tokens directly with eBay. Seller tokens and identity are encrypted using Windows DPAPI for the current Windows user and stored on the operator's PC. They are not sent to the notification service.

The account-deletion endpoint runs on Cloudflare Workers. After verifying eBay's signature, it stores the notification payload, account identifiers, event dates, and receipt time in Cloudflare D1. The application ID and secret needed to verify these messages are stored as Cloudflare secrets. Cloudflare and eBay also process network and service metadata under their own policies.

Retention and account controls

Use Disconnect this PC in Orbit Settings to remove the locally saved seller authorization. This does not remove existing listings, other Orbit product or order records, or copies on other devices. To withdraw the eBay grant itself, remove Orbit's authorization in your eBay account settings.

Deletion notifications currently remain in a private pending inbox. Automatic deletion of associated Orbit records has not been connected yet. Receipt of a notification does not mean those records have been erased. The operator must complete that processing before enabling production API inventory or listing jobs.

Limits and contact

This connection does not add advertising trackers, sell account data, or send seller tokens to AI services. This notice does not cover Orbit's separate browser-based sourcing, order tools, or optional AI features.

This is a private installation controlled by its account owner. For questions or a request concerning information held by this installation, contact the operator who provided access to it. If the application is made available to other users, this notice and an appropriate public contact method must be updated before they connect accounts.
